# CTaiko releases

Downloads for CTaiko, a taiko rhythm game: see [Releases](https://github.com/shrandonm/CTaikoRelease/releases).

- Windows: `CTaiko-setup.exe` (installs per user, no admin rights; updates itself)
- Android: `CTaiko.apk`

`ctaiko.json` and `ctaiko.json.sig` are the signed update manifest the game checks.
